# 3dVR - POLÍTICA DE SEGURIDAD:

## Versiones con soporte / Supported Versions:

Actualmente solo se ofrecen parches de seguridad para la última versión principal disponible en la rama `main`.

| Versión | Soporte actual     |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0   | :x:                |

## Reportar una vulnerabilidad / Reporting a Vulnerability:

Si has descubierto un problema o vulnerabilidad de seguridad en este proyecto:

1. **Mediante 'Issues':** dirígete a la pestaña "Issues" del repositorio para reportar cualquier problema o bug.
2. **Detalles del reporte:** Por favor incluye:
   - Descripción clara del problema de seguridad + captura de pantalla de dónde se encuentra.
   - El impacto potencial del fallo.

## Proceso de respuesta
- **Confirmación:** se confirmará en todo momento el reporte y se llevará a cabo una investigación para detectar qué ocurre.
- **Evaluación y corrección:** se evaluará el impacto y se trabajará en un parche, corrección o respuesta al usuario.
- **Divulgación responsable:** una vez corregida la vulnerabilidad y publicada la versión con la corrección, se publicará una nueva versión del proyecto.

Se agradece reportar cualquier bug para mejorar **3dVR**.
