# 3dVR
"3D Visual Render" es un renderizador de modelos 3D compatible con archivos GLB (local y online) y ficheros de SketchFab.
Proyecto de código abierto en desarrollo creado por Markel Cantón. Si encontráis un problema, se agradece ponerlo en "Issues".

> [!NOTE]
> - Carga de modelos locales y mediante URL (soporta GitHub Raw y Sketchfab).
> - Añadido de objetos/modelos secundarios en escena.
> - Puntos de control y manipulador orbital (WASD + ratón/táctil).
> - Generador y exportador de animaciones GLB.
> - Interfaz adaptada a dispositivos móviles y escritorio.
